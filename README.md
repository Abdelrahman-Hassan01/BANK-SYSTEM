# 🏦 Bank Management System

A simple console-based Bank Management System built with C++.

This is my second C++ project, created to practice the fundamentals I have learned and improve my ability to build a complete program from scratch.

## ✨ Features

- Create a new account
- Generate an account ID
- Login using ID and password
- Password attempts limit
- Check balance
- Deposit money
- Withdraw money
- View account information
- Logout

## 🛠️ Concepts Practiced

- Structs
- Functions
- Arrays
- Loops
- Conditional Statements
- Switch Statements
- References
- Searching through arrays
- Basic input validation

## 🎯 Purpose

The main goal of this project is to practice C++ fundamentals by building a complete console application and improving my problem-solving skills.

This is a learning project, not a real banking system.

As I continue learning C++, I plan to improve the project with more advanced concepts and better data management.
